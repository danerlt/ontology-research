## 摘录译文

查询最多只能嵌套三层。

## 中文要点

- 本页详述 v1 `POST /api/v1/ontologies/{ontologyRid}/objects/{objectType}/search` 的 JSON 查询语法。操作符覆盖比较（`lt/gt/lte/gte/eq`）、null 检查、数组包含、布尔 `not/and/or` 和文本项匹配。
- 支持的属性类型因操作符而异；例如比较可用于数字、字符串、日期和时间戳，`contains` 用于数组，文本 `prefix/phrase/anyTerm/allTerms` 用于字符串。
- 布尔查询嵌套最多 3 层。文本分词受空格/标点解析规则影响，官方说明解析规则可能变化；仅明确列出的前缀/词项规则可以做预期，不应把它看作通用全文搜索引擎。
- Object Storage v1 搜索最多返回 10,000 个对象，达到限制后继续分页报 `ObjectsExceededLimit`；null 属性不返回。详情页还解释排序与 groupBy 的边界，具体响应分页见端点页。
