## 英文原文短摘录（每个来源不超过 25 词）

> “An Action represents one application of an action type.”

## 摘录译文

一个 Action 表示对某个 Action Type 的一次应用。

## 中文要点

v2 API 基础页仍将 Action 定义为 Action Type 的一次应用，可用于通过 API 对本体应用变更。配套 v2 Apply Action 和 Validate Action 页面描述具体请求与结果，这张概念页自身未展开执行协议。v2 与 v1 的概念文案相同，但不能据此推断请求 schema、并发语义或分页行为相同。

## 疑问与待验证项

- 概念页没有承诺 v2 的事务、幂等、状态追踪和失败恢复规则；需从端点和 Action 治理页面核实。
- 文案与 v1 一致只是概念层相同，不表示 API 版本兼容。

## 复刻启示

- 版本化操作定义与执行实例分开建模；API adapter 保持 v1/v2 差异不渗透到画布 schema。
- Agent 工具调用流程需记录调用来源、动作版本、参数摘要和变更后的对象差异。
