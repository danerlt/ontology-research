## 英文原文短摘录（每个来源不超过 25 词）

> “Ontology changes are eventually consistent, and it may take few minutes for the API to reflect new Ontologies.”

摘录来源：[Ontology basics (v1)](https://www.palantir.com/docs/foundry/api/v1/ontology-resources)。

## 摘录译文

Ontology 变更采用最终一致性，API 可能需要几分钟才反映新建的本体。

## 中文要点

- 可读取的 v1 基础页将本体描述为表达现实概念的对象图，包含对象类型、属性、链接类型和动作类型；本体 API 提供访问这些资源的接口。
- 本体新增后 API 视图可能延迟几分钟，在此期间请求可能暂时收到 `OntologyNotFound`。这属于传播延迟，不应直接当成创建失败。
- 当前目录目标 `/api/ontology-resources/ontologies` 是分组基础路由；相邻的显式 v1 概念页可读，但无法通过该根路由单独载入，因此卡片按可确认的同主题信息记录。
