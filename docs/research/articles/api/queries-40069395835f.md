## 英文原文短摘录（每个来源不超过 25 词）

> “A query type represents a logic that can be run in the Ontology.”

## 摘录译文

Query Type 表示一段可在本体中运行的逻辑。

## 中文要点

- Query Type 封装可运行的查询逻辑；页面指出它可通过 Query Functions 创建。
- 此 v1 查询分组入口的概念与同组 `/query-basics` 子页一致；它不定义具体参数、输出、版本锁定或调用响应。
- 结合相邻接口，定义、枚举、按名读取和执行分别由 Query Type 元数据与 Execute Query API 负责。
