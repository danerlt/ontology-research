## 英文原文短摘录（每个来源不超过 25 词）

> “The Ontology represents the decisions in an enterprise, not simply the data.”

## 摘录译文

本体呈现企业中的决策，而不只是数据。

## 中文要点

- 本体将业务决策拆分为数据、逻辑、动作和安全四部分；企业决策需要同时理解事实、判断依据、执行效果与授权边界。
- 异构数据源、统计/优化/机器学习模型和业务规则都可以映射到共同的本体语义；确定性逻辑与 LLM 推理互补，不能让 LLM 取代受治理的业务规则。
- 面向人和 Agent 的数据读取、逻辑调用、工具执行与写回都受到运行时安全策略约束；决策输入、评估选项和操作结果可沿决策 lineage 留痕，动作可先暂存并交人审。

## 术语对照

| 英文术语 | 中文译法 | 本页语境 |
|---|---|---|
| decision-centric | 决策导向 | 将事实、判断、执行与安全围绕具体业务决策建模。 |
| logic binding | 逻辑绑定 | 将异构计算逻辑接入一致的工作流接口。 |
| decision lineage | 决策血缘 | 记录决策发生时使用的数据、逻辑、版本与应用。 |

## 疑问与待验证项

- 本页是产品理念和案例说明，不是具体 API 规范；每一种系统连接器、模型运行时和安全策略要另查技术文档。
- “实时”决策效果受来源系统刷新与模型部署方式影响，不能直接推断所有数据和动作均为同步。

## 复刻启示

- Agent 不能直接执行任意逻辑；应从本体中发现允许的查询、确定性函数与动作，并遵守对象、属性、路径和提交条件授权。
- 为建议与执行拆分阶段：记录输入依据、预演影响、人工审批或规则审批、执行写回、记录响应与审计结果。
