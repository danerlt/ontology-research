## 中文要点

- 官方中文页使用 `ExampleRestaurant` 示范按主键获取对象、分页、迭代、属性排序、布尔过滤、文本检索和聚合分组。
- `page()` 返回当前页、下一页令牌和数据；迭代器适合遍历集合。页面说明 v1/Phonograph 的结果上限为 10,000，而 Object Storage v2 没有该端点请求数限制。
- Python 查询字段使用 `object_type` 上的类型化属性；布尔过滤可组合，文本过滤区分任意词、所有词和按序短语，聚合可返回 count、数值指标、近似去重及分组结果。
