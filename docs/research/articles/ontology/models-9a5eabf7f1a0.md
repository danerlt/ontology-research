## 英文原文短摘录（每个来源不超过 25 词）

> “This page focuses on the last step: deploying an evaluated model into production.”

## 摘录译文

本页聚焦最后一步：将已评估的模型部署到生产环境。

## 中文要点

- 运作流程为在 Foundry 创建模型、配置直接部署、发布包装函数（必要时再用函数编排复杂逻辑），并在 Workshop、Vertex 等用户应用中进行实时推理。
- 模型结果可映射到对象类型属性，使最终用户通过预测、估值或分类等业务概念消费结果，无需直接理解模型内部细节。
- 模型也可先做批量推理并用数据集支撑本体对象；模型与本体对接可提高解释性、复用性，并支持在统一业务对象上下文中模拟变化。

## 术语对照

| 英文术语 | 中文译法 | 本页语境 |
|---|---|---|
| model deployment | 模型部署 | 把已评估模型发布为生产推理能力。 |
| wrapper function | 包装函数 | 为模型调用提供本体应用可消费的函数入口。 |
| live inference | 实时推理 | 在用户工作流中即时调用已部署模型。 |

## 疑问与待验证项

- 本文主流程说明直接部署和包装函数，但模型部署的验证、版本回退、输入漂移监测需查看模型治理文档。
- 绑定对象属性后，模型输出仍需说明版本和生成时间，避免把预测值误当成已确认事实。

## 复刻启示

- 把模型输出作为带模型版本、时间戳和输入血缘的语义属性/函数结果公开，消费方通过业务对象访问。
- 区分批量生成值和在线推理；将模型调用置于具备访问控制、可观测性与预算限制的函数运行时。
