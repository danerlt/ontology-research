## 英文原文短摘录（每个来源不超过 25 词）

> “You can search for any object type, property, link type, action type, shared properties, interfaces, or functions you are interested in.”

## 摘录译文

可以搜索对象类型、属性、链接类型、动作类型、共享属性、接口或函数。

## 中文要点

- 顶部搜索支持对象类型、属性、链接、动作、共享属性、接口和函数，并突出显示命中的字段。
- 用户可用方向键浏览结果预览，再打开选中资源；首页侧栏提供不同资源类型列表及筛选。
- 资源列表可按可见性、开发状态和索引问题过滤；详情页可返回首页并查看最近编辑及相关资源快捷入口。

## 术语对照

| 英文术语 | 中文译法 | 本页语境 |
|---|---|---|
| header search bar | 顶栏搜索 | 跨本体资源的统一搜索框。 |
| visibility | 可见性 | 列表筛选条件，用于区分资源可发现状态。 |
| issue column | 问题列 | 呈现数据源注册或重建索引异常的资源状态。 |

## 疑问与待验证项

- 搜索结果预览和键盘导航属于提升操作效率的细节，文档没有规定排序相关性算法。
- 索引错误与权限错误需要在 UI 中明确区分，避免用户把不可访问资源当成数据中断。

## 复刻启示

- 支持 Ctrl/Cmd+K 的全局资源搜索，索引资源名称、API 名、描述与属性。
- 资源列表提供类型、状态、可见性、数据连接/索引健康筛选；详情面板提供返回、最近资源和相关关系入口。
