## 英文原文短摘录（每个来源不超过 25 词）

> “An Ontology is a categorization of the world.”

## 摘录译文

Ontology 是对现实世界的一种分类。

## 中文要点

- 本体把数据集和模型映射为对象类型、属性、链接类型和操作类型；其数据集类比是入门捷径，但不能覆盖操作和授权语义。
- 页面还定义共享属性、角色、函数、接口和对象视图：共享属性统一字段语义，角色限定资源访问，函数读取本体数据并用于应用/动作。
- 对象视图是围绕单个对象展示属性、链接对象、指标及相关分析/工作流的应用入口。

## 术语对照

| 英文术语 | 中文译法 | 本页语境 |

| shared property | 共享属性 | 多个对象类型复用并集中管理元数据的属性。 |

| Object View | 对象视图 | 聚合单个对象信息与相关工作流的中心页面。 |

## 疑问与待验证项

- 此官方中文页明确标注机器翻译准确性尚未验证；本文术语如“操作类型”应以英文 action type 语义为准。
- 概念页没有给出画布上的布局模型；节点层级、交互和自动布局属于本地产品设计。

## 复刻启示

- 用资源类型和关系语义驱动画布，把动作、函数和对象视图作为与对象类型关联的资源，而不是把它们误绘为对象关系。
- 将本体角色映射到资源级授权，并在对象字段和推理路径读取时执行同一授权策略。
