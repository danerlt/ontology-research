## 中文要点

- 行内编辑与标准动作不同：参数默认使用对象现有值，允许逐属性修改；Workshop 和 Object Explorer 均可使用。
- Object Explorer 中每个属性最多配置一个行内编辑操作；该操作只能修改单一对象类型的单个对象，且默认值必须来自对象引用参数。
- 行内编辑采用批量校验/提交，而标准动作往往按顺序逐次提交；多个编辑若争写同一对象、链接或聚合约束，可能出错或产生与顺序执行不同的结果。
- 共享对象或链接对象相关的提交条件与行内编辑不兼容；文档警告批量写入可能违反逐个应用时成立的校验假设。中文页机器翻译未经验证。

## 疑问与待验证项

- 批量编辑是否原子提交、部分失败返回如何呈现，应按具体 Workshop/Object Explorer 路径进行验证。
- 示例指出共享聚合约束有风险；系统应检查同时提交的编辑集合，而不能只逐条预验证。

## 复刻启示

- 行内编辑 API 需要显式标记批次边界，并在提交前检测同对象/同链接冲突及依赖聚合的条件。
- UI 应区分当前值、编辑值与批量提交结果；执行校验需要和最终写入采用一致的对象版本语义。
