## 英文原文短摘录（每个来源不超过 25 词）

> “By default, functions are not allowed to call external APIs.”

## 摘录译文

默认情况下，函数不允许调用外部 API。

## 中文要点

- TSv1、TSv2 和 Python 函数均可调用外部源，但需在 Data Connection 配置 Source，并允许导出和导入到 Code Repositories。
- TSv2/Python 推荐用 source alias 作为稳定名称，Marketplace 安装时可映射到目标环境的不同 Source；TSv1 使用生成的 Source symbol，不支持 alias。
- 函数需要导入 Source 并声明使用它；不能假定普通第三方 HTTP 客户端或直接请求内部 Foundry URL 在无服务器和 Live Preview 环境都可运行。
- 需使用平台提供的 source-aware fetch/client 和正确的证书配置；Webhook 与函数执行环境可能不同，Webhook 可用并不保证函数 TLS 请求可用。

## 疑问与待验证项

- 外部请求的身份究竟使用 Source 凭据还是当前用户代理，需结合认证模式和各客户端 API 页面确认。
- 代码中 URL、证书和 Source alias 都可能随环境变化，安装后需执行真实连接冒烟检查。

## 复刻启示

- 函数出站网络默认拒绝；通过环境别名/凭据引用和最小权限 Source 显式开放，并对请求目标、TLS、超时及审计留痕。
- Marketplace 包将外部系统依赖暴露为可映射配置，不把源环境 URL 或 secret 写入代码。
