## 英文原文短摘录（每个来源不超过 25 词）

> “A webhook is a concept in Data Connection that enables sending a request to an external system.”

## 摘录译文

Webhook 是 Data Connection 中用于向外部系统发送请求的一种机制。

## 中文要点

- Writeback 在对象编辑之前执行且失败会阻止后续本体变更，并向用户返回错误；Action 中最多配置一个写回 Webhook，其输出可供后续规则使用。
- 写回可保证外部请求失败时不修改 Ontology，但外部请求成功后本体编辑仍可能失败，因此不是跨系统原子事务。
- Side effect 在其他规则之后执行，可配置多个且无确定顺序；用户可能在副作用完成前已看到 Action 成功。
- 单个副作用 Webhook 可接收多个 payload 并多次调用，调用顺序不保证；适合尽力通知或向多个外部系统写回。

## 术语对照

| 英文术语 | 中文译法 | 本页语境 |
|---|---|---|
| Writeback webhook | 写回 Webhook | 在本体编辑之前执行并可阻断 Action 的外部调用 |
| Side effect webhook | 副作用 Webhook | 本体编辑后异步/非阻断执行的外部调用 |
| Cross-system transaction | 跨系统事务 | Foundry 与外部系统共同完成的事务边界 |

## 疑问与待验证项

- Writeback 仅保证外部失败时不落本体，反向失败仍会造成系统间不一致；需要幂等键与补偿对账。
- 多个副作用执行无顺序保证，外部依赖存在先后要求时应改造集成而非依赖偶然顺序。

## 复刻启示

- 将外部同步请求和尽力副作用分别定义状态、错误可见性、重试机制和补偿队列。
- 成功反馈区分本体编辑成功和外部副作用完成，给管理员提供按请求 RID 对账的入口。
