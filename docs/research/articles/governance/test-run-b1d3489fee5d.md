## 英文原文短摘录（每个来源不超过 25 词）

> “The edits produced by a test run are not applied to your Ontology.”

## 摘录译文

测试运行产生的编辑不会应用到本体。

## 中文要点

- Test run 用填写的参数在当前本体分支、当前用户权限下评估 Action，并返回拟议对象/链接差异和执行细节；不真正写入本体。
- 结果包括编辑前后值、执行日志（依赖验证、提交条件、参数校验、编辑计算）、副作用预览和引用实体；错误分为管理员排错信息与用户提示。
- 只允许在表单布局运行，Action 有未保存编辑时不可运行；保存后才能验证当前配置。
- 编辑后才执行的通知、Webhook 和构建会跳过；但决定动作结果所需的函数、写回 Webhook 或外部资源调用仍可能执行，系统会提示并要求确认。

## 术语对照

## 疑问与待验证项

- “不会写本体”不等于“没有外部影响”；测试数据应避免真实写回 Webhook 或有副作用的函数。
- 执行日志暴露何种敏感参数/对象数据、结果如何留存，需在权限和审计模型中核实。

## 复刻启示

- 把测试运行拆成无写入模拟与需授权的外部依赖执行两类，执行前列出具体调用源并要求显式确认。
- 保存配置后在当前分支重放参数，展示对象差异、条件逐项结果、依赖轨迹及可见的用户错误。
