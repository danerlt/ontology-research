## 英文原文短摘录（每个来源不超过 25 词）

> “Rules define the logic of the action type that transforms the parameters into Ontology edits or other effects.”

## 摘录译文

规则定义 Action 类型的逻辑，将参数转换成本体编辑或其他效果。

## 中文要点

- 本体规则可创建/修改/删除对象，创建/删除多对多链接；一对一/一对多关系通过修改外键属性实现。
- Modify/Delete 规则不能引用本次 Action 新建的对象；Create or modify 可按对象引用选择更新或新建并生成/接收主键。
- Function 规则调用本体编辑函数，配置后不能再有其他规则；接口规则可作用于实现接口的多种对象。
- 通知在编辑应用后发送，但通知内容基于编辑前对象状态生成；Webhook 可在编辑前或编辑后调用外部系统。
- Schedule 规则触发构建；Foundry 启动构建后才应用本体编辑。

## 术语对照

| 英文术语 | 中文译法 | 本页语境 |
|---|---|---|
| Ontology rule | 本体规则 | 直接创建/更新/删除对象和链接的动作规则 |
| Foreign key link | 外键关系 | 通过更新对象外键属性建立/移除的一对一或一对多链接 |
| Side effect rule | 副作用规则 | 触发通知、Webhook 或构建等外部效果的规则 |

## 疑问与待验证项

- 通知内容读取编辑前状态、Webhook 可前后执行、Schedule 与本体编辑先后有差异；失败补偿和重试需分别验证。
- 新建对象不能被同一次 Modify/Delete 规则引用，复杂关联要考虑 Action 规则执行模型或函数动作。

## 复刻启示

- 在 Action 画布中将规则按“本体变更”和“副作用”区分，并展示每种规则的先后阶段与失败补偿。
- 提交预览应标出新对象主键、链接外键、旧/新快照及外部调用边界。
