## 中文要点

- Webhook 可作为 writeback 或副作用运行。Writeback 在对象变更前执行，失败会向用户报告并阻止本体变更；但外部成功后本体仍可能失败，因此不具备真正的跨系统原子性。
- 副作用在其他规则后执行，可配置多个且执行顺序不保证；用户可能已经看到本体写入成功，副作用随后才失败或完成。
- 批量 payload 可触发多次请求，但处理顺序不保证；适合 best-effort 通知或多系统写回，不适合依赖严格串行/全局事务的步骤。
- 页面建议基于目标时点选择 writeback 或副作用；官方中文页注明 AIP 机器翻译准确性未经验证。

## 疑问与待验证项

- 外部系统返回的输入/输出参数、超时和重试在后续章节；不同调用可能改变最终一致边界，需全页复核。
- 若writeback外部成功而Ontology提交失败，补偿/幂等和用户提示是调用方责任还是平台责任需核对完整错误章节。

## 复刻启示

- 把双写语义明确设计为非原子 Saga：持久化外部调用状态、幂等键、失败重试和补偿操作。
- UI 和审计呈现“本体已提交、外部同步待处理”等分阶段状态，不以单一成功标识掩盖最终一致。
