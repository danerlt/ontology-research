## 英文原文短摘录（每个来源不超过 25 词）

> Uploaded media is temporary unless you set it on an Ontology object's media reference property.

## 摘录译文

上传的媒体是临时的，除非将它写入本体对象的媒体引用属性。

## 中文要点

- TSv2/Python 通过 Media 类型访问、读取字节与元数据、上传和变换媒体，并能把媒体作为函数输入或输出；OSDK 的 `uploadMedia` / Python `upload_media` 返回 Media 引用。
- 临时上传不会自动成为持久对象数据；只有 Ontology edit 写入对象的 media reference 属性并应用编辑后，媒体才持久关联到对象。
- 功能支持存在语言差异：TSv1 提供更完整的媒体操作，包括文档 OCR 与音频转录；TSv2/Python 提供上传与属性基础操作，文档/音频专用处理需外部库或自定义代码。Live Preview 可从媒体集选择输入。

## 术语对照

## 疑问与待验证项

- 临时媒体的过期、容量、文件类型与访问控制策略在该页未集中列出；应查媒体集与目标租户限制。
- OCR/音频转录不是 TSv2/Python 的内建同等能力，需要确认外部依赖及敏感媒体处理规则。

## 复刻启示

- 文件上传应分离临时对象存储与本体对象关联；保存媒体属性必须经受权限校验的事务式编辑。
- 数据模型记录媒体元数据、引用来源与持久状态；预览/推理工作流需传输短期受控引用，避免误把临时上传当作永久文件。
